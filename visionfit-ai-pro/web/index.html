⚡ Bộ Mô Phỏng Biomechanics 33 Khớp

Offline Synthetic Engine

Mô phỏng chuỗi tọa độ 33 điểm dựa trên phương trình hình học và nhịp sinh học (chuẩn hàm demo() trong visionfit.py). Giúp bạn test nhanh quy trình thu thập dữ liệu, huấn luyện mạng AI và đếm rep mà không cần đứng trước camera.

Thông tin kỹ thuật mô phỏng:
  • 33 landmarks theo chuẩn MediaPipe pose topology.
  • Hông (23, 24), Vai (11, 12), Gối (25, 26), Cổ chân (27, 28), Khuỷu tay (13, 14), Cổ tay (15, 16).
  • Dao động sin(t) và cos(t) theo từng chu kỳ động tác cùng nhiễu Gaussian ngẫu nhiên.

Kiểm tra kết nối...

Bạn có thể chạy song song giao diện Web này với server Python web_server.py để tận dụng toàn bộ pipeline PyTorch của dự án:

Model PyTorch Mặc định models/action_demo.pt Mô hình Demo Temporal CNN
Dataset Huấn Luyện data/action_real.npz Định dạng X, y, subjects
Số Lớp Động Tác 4 Classes squat, push_up, lunge, standing

Lệnh dòng lệnh tiện ích (Chạy trong Terminal):

# 1. Khởi động server Web giao diện VisionFit: python web_server.py --port 8000 # 2. Hoặc nhấp đúp file tiện ích trên Windows: run_web.bat # 3. Huấn luyện lại mô hình PyTorch ActionNet: python visionfit.py train --data data/demo.npz --labels labels.json --out models/action_demo_new.pt --epochs 15 # 4. Chạy webcam nhận diện trực tiếp bằng PyTorch OpenCV: python live.py --source 0 --pose-model models/pose.pt --action-model models/action_demo.pt
